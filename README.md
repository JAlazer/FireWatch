# FireWatch

## Quick Description
A mobile app that forges the link between lifestyle and existing physiological data from wearable devices to inflammatory levels within the body.

There has been much research done within the medical field that points towards lifestyle and phsyiology having a correlation to inflammation. Some of the most common influences are poor diet, lack of sleep, or minimal physical activity. FireWatch aims to provide the user with overall awareness into their lifestyle and how certain aspects can point towards a certain level of inflammation through collecting and interpreting already-available physiological data from wearable devices (ex. Apple Watch).

This app is under development so stay tuned!
